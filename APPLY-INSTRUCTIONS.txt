Tamestorage quality and diagnostics update

Apply this package over the existing Tamestorage project:

1. Stop or restart Tamestorage after copying the files.
2. Install Python dependencies with: pip install -r requirements.txt
3. Keep your existing .env, users, uploads, logs, ac_control.json, and ac_statistics.json.
4. Open /admin to access Network test.
5. Open /aircon directly for the separate password-protected aircon portal.

New optional .env settings are documented in .env.example.
